# Full-Stack-Projects-using-MERN
Set of Projects from CodeChef, that I am using to practice hands-on MERN stack development.

## Current Project: Fitness App

### Project Status: 🚀 Ready to Start

**Goal**: Build a complete fitness web application that helps users explore exercises based on body parts, with workout demonstrations and related YouTube videos.

### Implementation Approach

#### 📋 **Step-by-Step Process**
1. **Phase 1**: Project Setup & Structure
2. **Phase 2**: React UI for Exercise Display (Part 1)
3. **Phase 3**: Express Backend with ExerciseDB API (Part 2)
4. **Phase 4**: YouTube Video Display (Part 3)
5. **Phase 5**: YouTube API Integration (Part 4)

#### 🛠️ **Technology Stack**
- **Frontend**: React.js with Hooks
- **Backend**: Express.js + Node.js
- **APIs**: ExerciseDB API, YouTube API
- **Styling**: CSS
